# Auto-Naming for Action Recording Sessions

## Overview

SheetNext now includes **LLM-powered auto-naming** for action recording sessions. After recording actions, the LLM analyzes the user's behavior and generates a meaningful, descriptive name for the task being performed.

## Features

### 1. Automatic Session Naming

When a recording session ends:
- LLM analyzes the recorded actions
- Generates a concise task name (3-8 words)
- Stores the name with session data
- Includes naming metadata (model used, action count)

### 2. Configurable Auto-Naming

**Options:**
- Enable/disable auto-naming
- Choose LLM model
- Set minimum actions required
- Customize naming prompt

### 3. Manual Regeneration

- Regenerate names for existing sessions
- Get all generated names
- Configure naming behavior

## Configuration

### Basic Setup

```javascript
const SN = new SheetNext(dom, {
    // Enable auto-naming (default: true)
    ACTION_AUTO_NAMING: true,
    
    // Model to use (default: 'llama')
    ACTION_AUTO_NAMING_MODEL: 'llama',
    
    // Minimum actions before naming (default: 3)
    ACTION_MIN_ACTIONS_FOR_NAMING: 3,
    
    // Backend
    BACKEND_URL: 'http://localhost:3000',
    AI_TOKEN: 'your-token'
});
```

### Advanced Configuration

```javascript
// Configure after initialization
SN.ActionRecorder.configureAutoNaming({
    enabled: true,
    model: 'llama-3.2-90b-vision-preview',
    minActionsForNaming: 5,
    namingPrompt: `Analyze these user actions and generate a concise task name.
The name should be 3-8 words and clearly describe the task.
Return ONLY the task name, no additional text.`
});
```

## Usage

### Start Recording

```javascript
// Start recording
await SN.ActionRecorder.startRecording();

// Perform actions...
// - Click on cell A1
// - Type "=SUM(B2:B10)"
// - Click bold button
// - Apply currency format

// Stop recording (auto-names the session)
await SN.ActionRecorder.stopRecording();

// Session is automatically named, e.g., "Creating SUM formula with formatting"
```

### Get Session Stats

```javascript
const stats = SN.ActionRecorder.getSessionStats();
console.log(stats);
// {
//   sessionId: "session_123",
//   sessionName: "Creating SUM formula with formatting",
//   isRecording: false,
//   actionCount: 15,
//   autoNaming: {
//     enabled: true,
//     generated: true,
//     model: "llama",
//     actionCount: 15
//   }
// }
```

### Manually Regenerate Name

```javascript
// Regenerate name for current session
const newName = await SN.ActionRecorder.regenerateSessionName();
console.log('New name:', newName);

// Regenerate for specific session (requires backend fetch)
const newName = await SN.ActionRecorder.regenerateSessionName('session_456');
```

### Get All Generated Names

```javascript
const names = SN.ActionRecorder.getGeneratedNames();
console.log(names);
// [
//   {
//     sessionId: "session_123",
//     name: "Creating SUM formula with formatting",
//     timestamp: 1709856000000,
//     actionCount: 15,
//     model: "llama"
//   },
//   ...
// ]
```

## Database Schema

### Action Sessions Table

```sql
CREATE TABLE action_sessions (
    id UUID PRIMARY KEY,
    user_id UUID NOT NULL,
    session_id VARCHAR(100) UNIQUE NOT NULL,
    session_name VARCHAR(500),              -- User-provided or generated name
    auto_generated_name VARCHAR(500),       -- LLM generated name
    auto_generated_by VARCHAR(100),         -- Model used for generation
    start_time TIMESTAMP,
    end_time TIMESTAMP,
    duration INTEGER,
    action_count INTEGER,
    screenshot_count INTEGER,
    actions JSONB,
    metadata JSONB,
    created_at TIMESTAMP
);

-- Indexes for searching
CREATE INDEX idx_action_sessions_session_name ON action_sessions(session_name);
CREATE INDEX idx_action_sessions_auto_name ON action_sessions(auto_generated_name);
```

## LLM Prompt

The default prompt for generating session names:

```
Analyze these user actions and generate a concise, descriptive name for the task being performed. 
The name should be 3-8 words and clearly describe what the user is doing.

Examples:
- "Creating SUM formula for monthly totals"
- "Formatting sales data as currency"
- "Building pivot table from raw data"
- "Setting up data validation dropdown"

Return ONLY the task name, no additional text.

User Actions:
click on button "Bold" in Sheet1
keyboard Enter in Sheet1
click on cell B10 in Sheet1
input =SUM(B2:B10) in Sheet1
cell_edit_end cell B10

Task Name:
```

## Custom Naming Prompts

You can customize the prompt for specific use cases:

```javascript
// Technical documentation style
SN.ActionRecorder.configureAutoNaming({
    namingPrompt: `Analyze these actions and generate a technical task name.
Use imperative mood and include specific functions/tools used.
Examples:
- "Apply SUM function to range B2:B10"
- "Format cells as currency with 2 decimals"
- "Create pivot table with sales data"
Return ONLY the task name.`
});

// User-friendly style
SN.ActionRecorder.configureAutoNaming({
    namingPrompt: `Describe what the user is doing in simple, friendly language.
Use natural language that a non-technical user would understand.
Examples:
- "Adding up numbers in a column"
- "Making the money look nice"
- "Creating a summary table"
Return ONLY the task name.`
});

// Multi-language support
SN.ActionRecorder.configureAutoNaming({
    namingPrompt: `Analiza estas acciones y genera un nombre descriptivo para la tarea.
El nombre debe tener 3-8 palabras y describir claramente lo que hace el usuario.
Devuelve SOLO el nombre de la tarea, sin texto adicional.`
});
```

## Best Practices

### 1. Minimum Actions

Set appropriate minimum actions to ensure meaningful names:

```javascript
// Too few actions = vague names
ACTION_MIN_ACTIONS_FOR_NAMING: 3

// Good balance
ACTION_MIN_ACTIONS_FOR_NAMING: 5

// More actions = more specific names
ACTION_MIN_ACTIONS_FOR_NAMING: 10
```

### 2. Model Selection

Choose appropriate model for your needs:

```javascript
// Fast, good for simple tasks
ACTION_AUTO_NAMING_MODEL: 'llama-3.2-1b'

// Balanced speed/quality
ACTION_AUTO_NAMING_MODEL: 'llama-3.2-3b'

// Best quality, slower
ACTION_AUTO_NAMING_MODEL: 'llama-3.2-90b-vision-preview'
```

### 3. Naming Cache

Consider caching generated names to reduce API calls:

```javascript
// Check if name already generated
const existing = SN.ActionRecorder.getGeneratedNames()
    .find(n => n.sessionId === sessionId);

if (existing) {
    console.log('Name already generated:', existing.name);
}
```

### 4. Review Generated Names

Allow users to review and edit generated names:

```javascript
// Get generated name
const stats = SN.ActionRecorder.getSessionStats();
console.log('Generated name:', stats.sessionName);

// Let user edit
const userApprovedName = prompt('Edit session name:', stats.sessionName);

// Save with approved name
// (Would require backend endpoint for updating session name)
```

## Troubleshooting

### Name Not Generated

**Check:**
1. Auto-naming is enabled
2. Minimum actions reached
3. AI module is available
4. Backend connection working

```javascript
const stats = SN.ActionRecorder.getSessionStats();
console.log('Auto-naming enabled:', stats.autoNaming.enabled);
console.log('Name generated:', stats.autoNaming.generated);
console.log('Action count:', stats.actionCount);
```

### Poor Quality Names

**Solutions:**
1. Increase minimum actions
2. Customize naming prompt
3. Use better model
4. Add more examples to prompt

```javascript
SN.ActionRecorder.configureAutoNaming({
    minActionsForNaming: 10,
    model: 'llama-3.2-90b-vision-preview',
    namingPrompt: `Your improved prompt with more examples...`
});
```

### Slow Generation

**Solutions:**
1. Use smaller/faster model
2. Reduce action sample size (currently 50 max)
3. Disable for short sessions
4. Generate asynchronously

```javascript
// Generate name after session saved
setTimeout(async () => {
    const name = await SN.ActionRecorder.regenerateSessionName();
    console.log('Name generated asynchronously:', name);
}, 1000);
```
